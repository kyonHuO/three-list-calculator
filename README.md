# 3列電卓

3つの独立した計算リストを備えた、個人用の電卓です。A-CalcM公式アプリではありません。

公開先: https://kyonhuo.github.io/three-list-calculator/

## iPhoneでホーム画面に追加

1. Safariで公開先を開きます
2. 共有メニューから「ホーム画面に追加」を選びます
3. 「Webアプリとして開く」が表示される場合はオンにして、「追加」を選びます
4. 初回は通信できる状態で開き、設定 → 「ホーム画面・保存・オフライン」で「オフライン使用の準備ができました」を確認してください

[Appleのホーム画面への追加手順](https://support.apple.com/guide/iphone/iph42ab2f3a7/ios)

## 保存とオフライン

- 3列の計算、メモリー、選択行、表示設定、最近の取り消し・やり直し履歴をブラウザ内に保存します
- 保存する履歴は通常、列ごと・方向ごとに直近20件までです。容量不足時は履歴を減らし、現在の計算と設定を優先します
- 安全な保存にはWeb Locks対応のブラウザが必要です。Safariでは15.4以降に搭載されています。保存できない場合は画面に警告を表示します
- 同時に自動保存できるのは1画面です。別の画面を開いた場合は、先の画面を閉じてから設定の「現在の計算で保存を再開」を選んでください。保存内容の置き換えが必要なときは確認が出ます
- 保存内容に異常がある場合や、新しい版の保存形式を古い版で開いた場合は、元の保存内容を自動的に消しません
- 更新は設定の「計算を保存して新しい版に更新」から行えます。保存に失敗した場合は自動再読込を止めます
- 入力した計算をアプリから外部へ送信する処理はありません。端末間同期やクラウドバックアップはありません
- Safariとホーム画面アプリで保存先が分かれる場合があります。サイトデータの削除、プライベートブラウズの終了、OSによる削除などでデータが失われる可能性があります。大切な計算はカメラボタンから画像でも保存してください

## 操作

- 行をタップ: その行を修正
- 約0.6秒の長押し: 押した行の上に空行を追加
- 左スワイプ: 削除ボタンを表示。削除は別のタップで確定
- ↶ / ↷: 選択列の取り消し・やり直し
- MC / M+ / M−: 列ごとのメモリー
- 小数計算は整数比で保持し、表示時に指定桁へ四捨五入

## 更新を公開するとき

`index.html`の`data-app-build`と`sw.js`の`APP_VERSION`を同じ新しい値に変更し、HTML、サービスワーカー、manifest、iconsをまとめて公開してください。サービスワーカーは必要な全ファイルとHTMLの版番号を確認してから更新を待機します。
